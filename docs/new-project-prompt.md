# New project prompt

Start a new Claude session in `Webroot` and paste:

```text
New immosite project. Use the immosite skill and ask me everything you need.
```

Claude then asks for the project details step by step (type, modules, apartment source, design
brief, marketer, mail recipients …) before it sets anything up.

Before starting: if the site gets a map, add `https://<domain>.test/` to the Mapbox token's allowed URLs.
